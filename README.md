## 🚀 Tentang Saya

Halo! Saya **Eliyanto Sarage**, Full-Stack Developer & AI Systems Architect, pendiri **[IRNK CODES](https://idugeni.github.io)**. Saya membangun aplikasi web modern, agentic tooling, dan integrasi AI dengan fokus pada arsitektur yang aman, performan, dan mudah dirawat.

- 🔭 **Sedang mengembangkan:** [`kirox`](https://github.com/idugeni/kirox), [`tabryn`](https://github.com/idugeni/tabryn), dan [`hostinger-mcp`](https://github.com/idugeni/hostinger-mcp) — tooling seputar AI coding agent & MCP server
- 🌱 **Sedang dipelajari:** Arsitektur agentic AI, protokol MCP (Model Context Protocol), dan hardening keamanan Supabase/PostgreSQL
- 👯 **Terbuka untuk kolaborasi:** proyek open-source di bidang web development, developer tooling, dan AI/automation
- 💬 **Tanyakan saya soal:** TypeScript, Next.js, React, Node.js, Python, arsitektur AI agent, dan keamanan aplikasi
- 📫 **Kontak:** lihat bagian [Hubungi Saya](#-hubungi-saya) di bawah
